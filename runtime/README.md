# ایمن بندر — Runtime

این پوشه مرز اجرای واقعی Target Platform است.

- `platform/` = رابط مرورگری Demo/Preview برای GitHub Pages
- `runtime/` = منطق اجرایی Target Platform
- `ARCHITECTURE/` = Source of Truth معماری
- `TESTS/` = کنترل‌های صحت

داده‌های TEST/SEED هرگز داده عملیاتی واقعی محسوب نمی‌شوند.
