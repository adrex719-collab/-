# Runtime Boundaries

## GitHub
GitHub is the canonical source for architecture and application code.

## Runtime
Macaly is the execution/preview environment. It must not become a separately maintained implementation.

## Browser demo
GitHub Pages is a visual/demo surface only.

## Security
Authorization and scope are enforced server-side. Client-side filtering is not a security control.

## Data classes
TEST/SEED
HISTORICAL
OPERATIONAL

Production deployment requires explicit approval and environment configuration. No production secrets belong in Git.
