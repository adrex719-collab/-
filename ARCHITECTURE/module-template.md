# Module Implementation Template

Every module uses this minimum structure:

1. Purpose and business semantics
2. Target schema
3. CORE dependencies
4. Scope and authorization
5. Workflow/state model
6. Runtime implementation
7. Audit/evidence
8. Historical Excel intake
9. Historical mapping/import/reconciliation
10. Automated tests
11. Completion gate

A module without all applicable sections is not COMPLETE.
If historical data is genuinely not applicable, the decision must be explicitly recorded with evidence.
