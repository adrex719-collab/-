# ایمن بندر — Target Platform

مرجع توسعه جدید پروژه ایمن بندر.

## Target Architecture
CORE → DOMAIN → GROUP → MODULE → SUBMODULE

## North Star

## Development rule
Target Architecture اولویت دارد؛ پروژه‌های قبلی فقط Source/Evidence هستند و مبنای پیاده‌سازی جدید نیستند.
